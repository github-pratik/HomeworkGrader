# Homework Grader

A web-based application designed to assist faculty and teaching assistants in grading homework assignments efficiently using modern web technologies and AI assistance.

## Link - https://homework-grader.vercel.app/

## Problem Statement

The Homework Grader system aims to streamline the homework grading process by providing:
- Tools for defining homework assignments and grading rubrics
- Interface for reviewing and grading student submissions
- AI-assisted grading suggestions
- Analysis of grading results and student performance

## Features

### Core Functionality
- **User Authentication**: Secure login for faculty and TAs
- **Homework Definition**: Create assignments with custom rubrics
- **Submission Review**: View and manage student submissions
- **Grading Interface**: Grade submissions with AI assistance
- **Results Analysis**: View grading statistics and metrics

### Technical Features
- Responsive Material-UI design
- React-based single-page application
- Comprehensive test coverage
- Modern web development practices

## Technology Stack

- **Frontend**: React.js
- **UI Framework**: Material-UI
- **Testing**: Jest and React Testing Library
- **Routing**: React Router
- **State Management**: React Context API

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation
1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm start`
4. Run tests: `npm test`
5. Build for production: `npm run build`

## Interface Heuristics Evaluation

1. **Visibility of System Status**
   - ✅ Implemented: Loading states and progress indicators
   - Justification: Users are always informed about system state

2. **Match Between System and Real World**
   - ✅ Implemented: Familiar grading terminology
   - Justification: Uses language familiar to educators

3. **User Control and Freedom**
   - ✅ Implemented: Undo/redo actions and clear navigation
   - Justification: Users can easily navigate and correct mistakes

4. **Consistency and Standards**
   - ✅ Implemented: Consistent UI patterns
   - Justification: Follows established design patterns

5. **Error Prevention**
   - ✅ Implemented: Form validation and confirmation dialogs
   - Justification: Prevents common errors

6. **Recognition Rather Than Recall**
   - ✅ Implemented: Clear labels and tooltips
   - Justification: Minimizes memory load

7. **Flexibility and Efficiency**
   - ✅ Implemented: Keyboard shortcuts and quick actions
   - Justification: Supports both novice and expert users

8. **Aesthetic and Minimalist Design**
   - ✅ Implemented: Clean interface
   - Justification: Reduces cognitive load

9. **Error Recovery**
   - ✅ Implemented: Clear error messages
   - Justification: Provides specific guidance

10. **Help and Documentation**
    - ✅ Implemented: Contextual help
    - Justification: Supports user learning
